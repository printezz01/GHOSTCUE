# GhostCue 👻

> Silent AI co-interviewer that coaches interviewers in real time and generates structured candidate reports.

**GhostCue listens to live job interviews, privately nudges the interviewer with follow-up suggestions, contradiction alerts, and coverage gaps — then produces an objective, evidence-based candidate report. The candidate never sees or hears the agent.**
